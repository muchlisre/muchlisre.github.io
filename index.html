Tambah Produk HTML dari Gemini

Tempel kode HTML dari Gemini atau tautkan file di folder produk/

Tips Penyimpanan:

• Klik Simpan & Tampilkan untuk langsung mencoba dan menyimpan produk di browser Anda.
• Untuk mempublikasikan permanen ke semua pengunjung GitHub Pages, klik Unduh sebagai file .html, simpan ke folder produk/, lalu tambahkan ke daftar PRODUK_BAWAAN di index.html.

Cara Menambahkan File HTML dari Gemini Secara Permanen

Agar produk HTML dari Gemini bisa diakses oleh semua orang di muchlisre.github.io:

  1. Simpan kode HTML dari Gemini sebagai file baru di dalam folder produk/, misalnya produk/aplikasi-saya.html.
  2. Buka file index.html dan cari bagian const PRODUK_BAWAAN = [...] di bagian bawah.
  3. Tambahkan baris produk baru seperti contoh berikut: 
    {
  id: 'aplikasi-saya',
  title: 'Nama Aplikasi Gemini',
  category: 'Tools AI',
  description: 'Deskripsi singkat produk HTML Anda.',
  url: 'produk/aplikasi-saya.html',
  date: '2026'
}
  4. Push perubahan ke GitHub, dan produk Anda langsung tampil di menu Produk Gemini!
