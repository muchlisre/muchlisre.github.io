Cara Menambahkan Produk & Thumbnail Permanen

  1. Simpan kode HTML dari Gemini ke dalam folder produk/, misalnya produk/aplikasi-baru.html.
  2. Buka file produk-data.js dan tambahkan objek baru ke PRODUK_BAWAAN: 
    {
  id: 'aplikasi-baru',
  title: 'Nama Aplikasi Gemini',
  category: 'Tools AI',
  description: 'Deskripsi singkat produk HTML Anda.',
  url: 'produk/aplikasi-baru.html',
  thumbnail: '', // Kosongkan untuk otomatis Live Thumbnail HTML, atau isi path gambar
  date: '2026',
  featured: true
}
